# PX4-Autopilot

> **This is the SuperInstance fork of [PX4 Autopilot](https://github.com/PX4/PX4-Autopilot).**
> For the main project, documentation, and contribution guidelines, see the upstream repository.

## What's Different

This fork tracks upstream PX4 with SuperInstance-specific modifications for:

- **Conservation integration** — connects PX4 to the `conservation-spectral` pipeline via `octomap-conservation-poc`
- **Agent coordination** — A2A protocol support for multi-drone fleet management
- **Custom modules** — experimental autopilot modules for the SuperInstance fleet
